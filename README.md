# quanttide-gallery-of-organization-management

量潮组织管理案例集 — 领域实践案例与成果展示。

## 概述

本仓库用于维护量潮组织管理领域的案例内容，包括：

- [role/index.md](role/index.md)：角色案例集入口（职务制度设计案例）。
- [role/representative.md](role/representative.md)：公司代表——一线代表职务的权责闭环。
- [role/secretary.md](role/secretary.md)：秘书制度——三层秘书架构与管理者孵化通道。
- [role/rank.md](role/rank.md)：职级制度——五序列职级体系与晋升通道。
- [department/deliberative-department.md](department/deliberative-department.md)：议事部门——三权并列体制下的议事出口。
