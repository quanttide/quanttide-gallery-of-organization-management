# 组织管理案例·公司代表：代表职务的权责闭环

> 本案例整理自《量潮公司代表章程》文本，按案例体裁改写，作为职务制度设计案例收录。本篇面向**治理制度设计者与公司代表**，回答一个问题：如何设计一个权责对等、有保障也有约束的一线代表职务？

## 一、代表职务的定位

公司实行创始人、上议院、下议院三权并列的治理体制：上议院代表股东意志行使所有权，下议院代表一线执行者行使经营权与民意表达职能。公司代表是下议院中的基本单元——由一线成员选举产生，把一线的声音带进正式审议，把治理层的决议带回一线。

代表是公司治理结构中的法定职务，经选举或任命产生后即享有制度规定的职权，并承担相应职责。整个制度的设计主线只有一条：权责对等。职权与职责在范围、强度上一一对应，互为条件，不可分割。

**要点**：代表制度的价值不在选出一个人，而在建立一条一线与治理层之间的双向通道。

## 二、谁能当代表，谁来选代表

代表资格的门槛围绕议事能力设置：

| 事项 | 规则 |
|------|------|
| 被选举资格 | 达到 L2 及以上职级，或具有培训生身份 |
| 提名限制 | L1 级成员不可被提名为代表 |
| 资格底线 | L0 级成员不具有代表资格 |
| 选举权 | 全体 L1 及以上成员 |
| 特殊群体 | 实习生享有选举权，实训生不具有 |

这套门槛的设计逻辑：代表要参与实质审议，必须经过系统训练并具备基本的议事能力。职级度量经验与训练程度，是常规通道；培训生身份提供绕开职级资历的快速通道，两条通道并行。

**要点**：资格门槛看的是议事能力，不是行政资历。

## 三、五项职权：覆盖履职全流程

代表的核心职权由五项权能构成，覆盖从知情到异议的全流程：

| 权能 | 核心内容 |
|------|----------|
| 信息获取权 | 获取与履职相关的一切必要信息与文件 |
| 提案权 | 就公司经营管理的任何事项提出正式议案，并要求列入议程 |
| 审议权 | 提出询问、提出修正案、自由发表意见 |
| 表决权 | 投赞成、反对或弃权票，仅受表决规则约束 |
| 程序异议权 | 对违反规定的会议或表决程序提出异议 |

五项权能层层递进：信息获取是审议的前提，审议是表决的前提，程序异议则守护前面所有环节的正当性。几处值得注意的设计：

1. 信息瑕疵豁免：信息存在重大遗漏或虚假的，代表有权拒绝表决或投反对票，并免于承担因信息不实导致的判断失误责任——信息质量责任压回给提案方；
2. 附议门槛：提案与修正案达到规定附议门槛的，议事机构应在规定期限内审议并作出决议——防止提案被搁置；
3. 表决独立：表决权不受任何个人或机构的指令、施压或不当影响。

**要点**：职权设计的关键不是给了多少权，而是让每个环节的失效场景——信息不实、提案被搁置、表决被施压、程序被打乱——都有对应的救济。

## 四、五项义务：与职权一一对应

每项职权都对应一项履职义务，权责逐项闭环：

| 职权 | 对应义务 | 义务要点 |
|------|----------|----------|
| 信息获取权 | 信息合规与保密 | 明确请求范围与目的；机密信息保密至任期结束后；不用于内幕交易 |
| 提案权 | 提案诚信 | 有事实依据、有具体方案；对匿名意见保密 |
| 审议权 | 审议勤勉 | 不无故缺席；围绕议题辩论；禁止人身攻击 |
| 表决权 | 独立与忠实 | 以公司整体合法利益为判断；利害关系主动回避；不接受利益输送 |
| 程序异议权 | 程序善意 | 说明条款依据；尊重裁定结果；不重复异议 |

**要点**：不存在无义务的职权——权能被行使的同时，滥用该权能的边界也被同时划定。

## 五、说反话的保障：辩论与豁免

代表制度能否运转，取决于代表敢不敢说反话。制度提供了四层保障：

1. 辩论组织原则：议题聚焦（制止跑题但不压制实质质疑）、意见平衡（正反双方呈现时间大体均等）、主持人中立（不预设立场、不率先表态）；
2. 内部合规沟通保护：代表在内部渠道的正常业务探讨和不同意见表达，不得作为降级、降薪、解除劳动合同等报复性对待的依据；
3. 反对意见豁免：依法依规提出的反对意见、投出的反对票属正当职务行为，不得因此遭受报复；豁免不延伸至违反忠实勤勉义务的法律责任；
4. 履职记录：所有表决结果（含赞成、反对、弃权）正式记录在案，存入个人履职档案——既是考核依据，也是表决免责的凭证。

**要点**：豁免保护的是依规反对，不是免责反对——履职记录让每一次反对都可追溯、可检验。

## 六、职权被侵害时的救济

任何个人、机构或内部规则，不得以任何形式限制、架空或剥夺代表职权。代表认为决议或命令侵害其职权的，有权拒绝执行，并有权向董事会提出书面申诉；申诉受理期间，暂停执行相关决议。经董事会裁定申诉不成立的，代表应立即执行该决议，拒不执行的按怠于履职处理。

救济的另一面是约束：代表不得以放弃职权为由推卸应负职责；怠于履职或滥用职权造成公司损失的，依法依规承担责任。

**要点**：救济程序自带终局性——申诉有受理期、裁定有强制力，既不让代表维权无门，也不让申诉成为拖延执行的借口。

## 七、进入有门槛，退出有程序

代表资格因下列情形终止：任期届满未获连任、主动辞职、被罢免、丧失代表资格（降级至 L1 及以下、培训生身份终止）、离职或解除劳动关系。

其中罢免是分量最重的退出程序，设置了双重门槛：罢免提案须经下议院三分之一以上代表联名提出，经全体有选举权的成员投票表决，获三分之二以上多数通过方可生效。可启动罢免的情形限于四类：连续三次无故缺席审议与表决、严重违反忠实勤勉义务、利用职权谋取不正当利益、因故意或重大过失给公司造成重大损失。

无论以何种方式退出，代表资格终止前须完成交接：整理移交履职文件与记录、汇报未完成事项、协助新人接管，由议事机构出具交接确认书。

**要点**：罢免的联名门槛加超级多数，防止代表职务被轻易动摇；交接确认书让退出责任可验收。

## 八、制度设计清单

若要把这套代表制度迁移到自己的组织，以下要素值得整体考虑：

1. 资格门槛：以议事能力为标准设置被选举资格，常规通道与快速通道并行；
2. 权责闭环：每项职权对应一项义务，不设无责之权；
3. 全流程权能：信息—提案—审议—表决—异议，每个失效场景有救济；
4. 反对保障：辩论原则、合规沟通保护、反对豁免、履职记录四层叠加；
5. 申诉终局：救济程序有受理期、有强制力；
6. 退出门槛：罢免需联名与超级多数双门槛，交接有确认书。
